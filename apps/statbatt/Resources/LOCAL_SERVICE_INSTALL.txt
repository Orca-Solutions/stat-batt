StatBatt local development build 9

This Apple Development-signed application is for this Mac's local testing. The
Installer package is unsigned and not notarized for public distribution.

1. Open StatBatt-LOCAL-DEVELOPMENT.pkg and approve macOS Installer's administrator
   request. It installs into /Library/Application Support/StatBattLocal and adds
   a separate StatBatt Local launcher in Applications. The existing StatBatt app
   and Shortcuts are preserved. This package refuses to overwrite a prior local
   service installation.
2. Open StatBatt Local from Applications. Use Set up background service and allow
   StatBatt in macOS Background Items when prompted. The app checks signed peers;
   installing or registering the service never enables temperature control.
3. Use Set to 80% / Set to 100% for Apple's native charge limits. If a shortcut is
   missing, the app opens its bundled signed import; Apple requires Add Shortcut
   confirmation. No manual shortcut authoring is required.

Automatic temperature control remains unavailable until qualified. An explicitly
enabled qualification build may offer one two-second adapter test. That test uses battery
power briefly, restores adapter input, and does not enable an automatic policy.
Estimated temperature is labeled as such. Control sessions never auto-restart.

Use Stop & restore before removing the service. Do not delete or replace a service
bundle while an operation or recovery is pending. A verified update/uninstall flow
is required before replacing a previous local service installation.
